# ADR-0019 白话版 — tools 多样性扩展 接下来做什么

> 配套 [0019-feature-tools-diversity.md](0019-feature-tools-diversity.md) 的简化说明.
> 这份只讲 "做什么 / 为什么 / 多大工作量", 不讲架构细节.

---

## 一句话总结

现在的 LLM 只能在本地 workspace 读写文件 + 跑 bash, 太弱了. 我们要让它能联网、能管任务、能中途问你、能派 sub-agent、能看图读 Office.

---

## 接下来按顺序做的 9 件事

### 阶段 1: 修通 bash (今天就能做, 最优先)
- **做什么**: 让 Pi Agent 知道你的 bash 在哪 (你装的 Git for Windows 在非常规路径, 现在找不到)
- **为什么**: bash 是所有 tool 的依赖, 没它 LLM 啥都干不了
- **做完之后**: 配一次路径, 之后 LLM 能跑任意 shell 命令
- **工作量**: 半天

### 阶段 2: 给 bash 加沙箱 (1-2 天)
- **做什么**: bash 跑命令时, 工作目录限定在当前 workspace 内
- **为什么**: 现在 bash 是"裸跑", 能跑任何命令, 不安全
- **做完之后**: 跑出 workspace 范围的命令会弹窗让你确认
- **工作量**: 1-2 天

### 阶段 3: 加联网 (1 周)
- **做什么**: 给 LLM 加 `web_search` (搜) 和 `web_fetch` (读网页) 两个能力
- **为什么**: LLM 训练数据有截止日期, 没法知道最新新闻/文档/产品价格
- **做完之后**: LLM 能查实时信息, 答案不再"过时"
- **工作量**: 1 周 (要存 API key 到 keychain)

### 阶段 4: LLM 能在中途问你 (1 周)
- **做什么**: LLM 跑着跑着, 弹个窗问你"接下来 A 还是 B?" / "你看这个方案行不行?"
- **为什么**: 现在 LLM 只能埋头跑, 跑完才发现跑偏了
- **做完之后**: 复杂任务能"边做边对齐", 减少返工
- **工作量**: 1 周

### 阶段 5: LLM 自己维护 todo (半天)
- **做什么**: LLM 把长任务拆成 todo, 你能看到进度
- **为什么**: 长任务容易"跑着跑着忘了原本要做什么"
- **做完之后**: 任务透明, 知道 LLM 当前在干啥
- **工作量**: 半天

### 阶段 6: LLM 能跨 session 记东西 (1 周)
- **做什么**: LLM 写笔记, 下次新 session 能读 (e.g. "这个项目用什么 build 工具")
- **为什么**: 现在每个 session 都从零开始, LLM 不记得你之前说过啥
- **做完之后**: 长期项目越来越顺手
- **工作量**: 1 周

### 阶段 7: 把所有 tool 改得更好用 (2 周, 可跟 4-6 并行)
- **做什么**: 7 个小改进打包:
  - 弹窗加"本次不再问"复选框
  - web_fetch / read 结果缓存 5 分钟
  - 每个 tool 每 session 调用次数上限
  - tool 出错时给更清楚的错误
  - 写操作日志, 出问题能查
  - 多个 tool 并行时 UI 标清楚
  - tool 模板跨 workspace 复用
- **为什么**: 现在的 tool 体验是"能跑但糙", 改完会顺很多
- **做完之后**: 用起来更顺, 出问题更容易排查
- **工作量**: 2 周 (可跟 4 / 5 / 6 并行)

### 阶段 8: LLM 能用图片 / 文档 / 子代理 / git (2 周)
- **做什么**: 4 块能力打包:
  - 看图 (OCR / 描述) + 读 PDF / Word / Excel
  - LLM 能派 sub-agent 干子任务 (跟 Claude Code 同款)
  - 结构化 git 操作 (status / diff / commit / push) + 自动跑 lint / test
  - 文生图
- **为什么**: 现在的 LLM 只能"看文字", 现实项目有图有文档有代码
- **做完之后**: 真正能当"全能助手"用
- **工作量**: 2 周

### 阶段 9: 杂项 (不排期, v0.8+ 再说)
- 时间 / 计算器 / 单位换算 / JSON 查询 / 天气 / 翻译 / 邮件通知等
- **工作量**: 不排期, 有需求再做

---

## 总时间

- **串行做**: 约 8 周
- **并行做** (阶段 7 横切可跟 4-6 并行): 约 5 周

---

## 现在第一件

**阶段 1 (修通 bash)** — 半天搞定, 优先级最高.

原因: 没它, 后面所有阶段 (尤其阶段 3 联网 / 阶段 8 子代理) 都没法验证.

---

## 阶段 1 完成后, 你能看到什么

1. 进 Settings → Bash 路径, 粘贴你的 bash 路径 → 立刻显示版本号
2. LLM 跑 `node -v` → 看到 v24.16.0
3. LLM 跑 `ls -la` → 看到目录列表
4. LLM 能正常用 read / write / edit 工具 (之前 bash 跑不了, 这些 tool 的端到端测试也不完整)

跑通这 4 步, 阶段 1 完成.
