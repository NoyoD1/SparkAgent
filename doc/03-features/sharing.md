> 状态: ❌ 0%
> 最后更新: 2026-08-16
> spec 涉及: v0.8 phase 新增

---

## 1. Spec

**协作 = 用户想把自己 session 拿出去用、给别人看、或者团队共享**。但**数据本机第一**原则限制了一些形态。

### 1.1 必备能力（v0.8 必做）

- ❌ **Session 导出**（本地）
  - Markdown（含 tool calls）
  - JSON（完整结构化）
  - 导出到剪贴板 / 文件
- ❌ **Session 分享链接**（端到端加密 + 过期）
  - 用户点"分享" → 生成加密链接
  - 链接含 session 内容（加密） + 过期时间
  - 接收方点链接 → 在网页查看（不需安装 Pi Agent）
  - 类似 Claude Artifacts 体验
- ❌ **设置过期时间**（1 天 / 7 天 / 30 天 / 永不过期）

### 1.2 商业化相关（待 user 拍板）

- ❌ **团队空间**（多用户共享 session / workspace / config）
- ❌ **B 端 server 端**：C 方案部署后才有意义
- ❌ **使用统计 / 配额**

### 1.3 不做什么

- ❌ 实时协作（多用户同时编辑一个 session）— **不做**
- ❌ 评论 / 点赞 / 关注 — **不做**
- ❌ 公开 marketplace / gallery — v2.0+ 再说
- ❌ 匿名分享（必须登录或自托管）— 跟"数据本机"原则冲突
